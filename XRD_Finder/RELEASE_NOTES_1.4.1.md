# XRD Phase Finder 1.4.1 — Optimization

Version 1.4.1 is an optimization and reliability update for XRD Phase Finder.

## Improvements

- Optimizes startup, multi-pattern rendering, candidate-source loading, and background status reporting.
- Keeps already working packages in the shared Sci environment unchanged during installation and updates.
- Preserves an existing Sci environment when repair is required instead of deleting it automatically.
- Treats non-critical package metadata warnings as diagnostic when the complete runtime self-test passes.
- Presents first-run guidance, scientific-environment setup notifications, progress messages, and feature cards in English.

Scientific Match, Gain, phase assignment, quantification, and XPFF project behavior remain unchanged.
