# XRD Phase Finder 1.3.0

## Portable projects and series

- Save complete work as one portable `.xpff` file containing XRD patterns, user CIF references, series, phase assignments and plot state.
- Open `.xpff` projects directly from Windows Explorer after installation.
- Create multiple series, import folders by drag and drop and toggle a complete series at once.
- Use Save for the current project or Save As for a new container.
- Preserve the project-tree expansion state while editing and reopening a project.

## Multi-pattern figures

- Show a separate scalable sample label and local phase key for every observed pattern.
- Reuse one color for the same phase throughout a multi-pattern figure.
- Display genuine two-phase peak overlap with split-color markers.
- Edit phase display names used in tables and figure annotations.
- Configure outward axis ticks as well as grid color and line width.

## Marker attribution

- Keep candidate preview profiles and sticks independent from accepted-phase display layers.
- Apply marker positions consistently to normalized and stacked patterns.
- Require a material fitted-profile contribution before a phase can color an experimental peak.
- Use five-sigma significance filtering without treating neighbouring diffraction peaks as noise.

## Windows installer

- Register `.xpff` as an XRD Phase Finder File.
- Forward an opened project path through the startup preview into the application.
- Continue using and repairing the shared `%LocalAppData%\Sci` scientific Python environment.
