# XRD Phase Finder 1.2.2

## Publication figure export

- Added a dedicated export window with a live preview.
- Added PNG, TIFF and JPEG output.
- Added selectable 1×–4× canvas scale.
- Added configurable print resolution from 72 to 1200 dpi.
- Added output dimensions in pixels and millimetres.
- Preserved the visible plot composition, legend, axes, grid and tick marks.

## Installer

- Removed the obsolete pre-installation information page about legacy runtime folders.

## Analysis

- Match, Gain, indexed unit-cell refinement and phase-quantity logic are unchanged from version 1.2.1.
