# XRD Phase Finder 1.5.0

Version 1.5.0 improves performance and reliability while keeping the established Match, Gain, phase-assignment and XPFF workflows.

## Improvements

- Adds a catalogue of complementary XRD tools with verified downloads and explicit installation confirmation.
- Keeps every application independent: each tool has its own installer, updater and uninstall entry.
- Improves startup, candidate-source loading and multi-pattern rendering performance.
- Preserves a working shared scientific environment and installs only missing or incompatible requirements.
- Reports long-running searches and setup failures more clearly without blocking the interface unnecessarily.

XRD Phase Finder continues to work as a standalone application. Installing additional XRD tools is optional.
